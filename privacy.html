Kebijakan Privasi

Halaman ini adalah template awal dan harus disesuaikan dengan praktik data aktual website sebelum dipublikasikan.

Data akun

Jika pengguna memilih membuat akun, website dapat menyimpan email dan kredensial yang telah di-hash untuk autentikasi dan fitur favorit.

Cookie dan sesi

Website dapat menggunakan cookie sesi untuk mempertahankan status login. Pengunjung yang tidak login tetap dapat menggunakan fitur utama.

Data pihak ketiga

Data pertandingan dapat berasal dari penyedia API pihak ketiga. Kebijakan penyedia tersebut perlu diperiksa sebelum penggunaan komersial.
